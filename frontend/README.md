# SmogSlayer frontend

React 19 + TanStack Start + Tailwind 4. It shows the animated intro, then a dashboard that calls the SmogSlayer API (`../backend`).

```
npm install            # or: bun install
cp .env.example .env   # set VITE_API_URL if the API is not on http://127.0.0.1:5001
npm run dev
npm run test
npm run format         # Prettier, to keep files tidy
```
